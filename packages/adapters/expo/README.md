# @uaif/adapter-expo

Expo/React Native adapter for the Universal Application Integration Framework (UAIF).

## Installation

```bash
npm install @uaif/adapter-expo @uaif/core
```

## Usage

```typescript
import { ExpoAdapter } from '@uaif/adapter-expo';

const adapter = new ExpoAdapter({
  // Expo configuration
});
```
